## What Are Templates

A Template is a tool that helps create Systems and Components inside Witboost. It loads skeletons of code, templates in variables from user input, and publishes the result to a Git provider. This way, organizations can standardize their development process and ensure consistency across projects by giving developers a predefined structure and set of best practices.

A template is composed of two main parts:
- The **wizard**, created from `template.yaml` — what the user sees and fills in
- The **skeleton**, defined in the `skeleton/` folder — templated files that become the repository contents

Every project in Witboost is represented by a **descriptor**, a YAML file that defines business metadata, infrastructure metadata, and other information required to automate deployment. The descriptor is generated by Witboost, which retrieves all `catalog-info.yaml` files from each component of the project and assembles them into a single unified descriptor. Templates ensure these files are correctly generated with all required metadata.
