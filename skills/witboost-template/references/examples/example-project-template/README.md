# Example Project Template

In this example, we provide a base project template for creating new Data Product within the Witboost platform.

Looking at terminology within the Witboost platform, Witboost works with **Projects** and **Components**. 
  - **Projects** are high-level organizational units that group related components together. In this example, a Witboost project represents a new Data Product
  - **Components** are individual pieces of functionality or services within a project. In this example, a Witboost component represents a specific part of the Data Product.
